# Python Productivity Application

## Overview
The Python Productivity Application is designed to help users track their productivity by logging productive and distracted hours for various tasks. The application calculates productivity rates and saves the data for future reference.

## Usage
1. Clone the repository or download the files.
2. Ensure you have Python installed on your machine.
3. Run `main.py` to start the application.
4. Follow the prompts to enter your productivity data.
